- **Audience:** Mail order team.
- **Who is on screen:** Maria (portal), Riley (fill, ship), Robin (check, email).
- **Spec:** `cypress/training/osv-20-refill-start-to-finish.cy.ts`; narration `cypress/training/narration/osv-20-refill-start-to-finish.json` (Nova, 1.25x).
