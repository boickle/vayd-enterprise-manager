# OSV-23. Pickup orders

- **Audience:** Mail order team.
- **Who is on screen:** Maria (cart), Riley, Robin.
- **Spec:** `cypress/training/osv-23-pickup.cy.ts`; narration `cypress/training/narration/osv-23-pickup.json` (Nova, 1.25x).
- **Demo data:** Dental chews in Maria’s cart; pickup at the Brunswick office.
- **Written:** Nov 11, 2026, from the owner’s request for a full Mail Order series.

## Narration

| Line | Says |
|---|---|
| `k01-why` | Some families pick up at an office instead of having it shipped. |
| `k02-choose` | In the cart, Maria chooses pickup at the Brunswick office. |
| `k03-place` | Place order. |
| `k04-fill` | It's filled like any order. |
| `k05-filled` | Mark filled. |
| `k06-pickup` | Instead of ship, it's ready for pickup. No shipping label. |
| `k07-bag` | Bag it for the office, then send it to check. |
| `k08-check` | A second person checks it, as always. |
| `k09-tell` | Then let the client know it's ready to pick up. |
| `k09b-email` | Click Email client. It's already worded for a pickup. |
| `k10-send` | Send the email. |
| `k11-mistakes` | The most common mistakes: buying a shipping label for a pickup order, and sending the bag to the wrong office. |
| `k12-remember` | Remember: pickup orders skip the label, but still get a second check and a message to the client. |
