# Labs training videos

Short videos (2 to 3 minutes, one task each) for the Labs module at go-live on Scout. Each script is checked against the app on the TEST stack before it is recorded (`cypress/training/README.md`). Open questions, possible bugs and demo data are in `docs/training/labs.md`.

Demo world (same as every training series):
- Riveras: Maria; Maple, Juniper and Pepper.
- Chens: Tom; Biscuit.
- Staff: Dr. Avery Lane and Dr. Priya Shah (doctors), Jordan Pike (tech), Casey Morgan (client liaison), Robin Hale (manager).

| ID | Title | Audience | Priority |
|---|---|---|---|
| LV-01 | Run an in-house lab in the visit | Techs, doctors | Must-have |
| LV-02 | Finish later: the Waiting to run list | Techs | Must-have |
| LV-03 | Send tests to IDEXX from the visit | Techs | Must-have |
| LV-04 | Finish in IDEXX: specimen questions, order, requisition | Techs, doctors | Must-have |
| LV-05 | Track and cancel IDEXX orders | Techs | Must-have |
| LV-06 | Review an IDEXX result | Doctors | Must-have |
| LV-07 | When a tech marks a result reviewed | Techs | Must-have |
| LV-08 | Client summary and emailing results | Doctors (techs send) | Must-have |
| LV-09 | Unmatched IDEXX results | Techs | Must-have (cutover) |
| LV-10 | IDEXX lab charges on the bill | CLs | Must-have |
| LV-11 | Wrong pet or removed lab charge | Techs, CLs | Nice to have |
| LV-12 | Lab history on the chart, including eVet | Doctors, techs | Nice to have (must once eVet forms are loaded) |
| LV-13 | Set up a lab form | Management (MD, PM, admin) | Nice to have (after LAB-06 and LAB-09) |

LV-01 and LV-02 replace the lab half of "EMR V7 – Patient alerts and in-house labs", which shows pre-filled forms.
