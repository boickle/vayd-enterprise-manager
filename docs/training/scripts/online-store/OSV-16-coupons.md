# OSV-16. Coupons

- **Audience:** managers.
- **Length:** 2 minutes.
- **Watch first:** OSV-15.
- **The one thing to remember:** set the limits (once per customer, single use) before you share a code.

## Status: not walked

The **Coupons** tab exists (Pharmacy → Store → **Coupons**) and its labels come from the code: **Code**, **Discount**, **Limits** (**Once per customer**, **Single use**, **Unlimited**), **Subtotal over**, **Ends**, **Used**. I didn't open it. Walk it in the dry run before recording.

## Why (opening)

"A coupon is a code families type in the cart for money off. Set its limits before you share it, or it can be used again and again."

## Closing

"The most common mistakes: sharing a code with no limits, and making a new code instead of ending an old one. Remember: set the limits (once per customer, single use) before you share a code."

## Notes

- Only admins and practice managers can create coupons (D5); lead CLs can only issue an existing one.
