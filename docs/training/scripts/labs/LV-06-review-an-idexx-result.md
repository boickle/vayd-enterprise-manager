# LV-06. Review an IDEXX result

- **Audience:** doctors.
- **Length:** 2½ minutes.
- **Watch first:** none.
- **The one thing to remember:** read the out-of-range values first. **Mark reviewed** tells the team the result is safe to release.

## Why (opening)

"Every IDEXX result comes to the ordering doctor as a task. Until it's marked reviewed, nobody should send it to the family."

## What else you can do here

- **PDF**: IDEXX's report.
- **Mark as not reviewed** undoes it.
- **Draft client summary** (LV-08).

## What other roles see

- Techs see **Mark reviewed** too, but must pick a reason (LV-07).
- Client liaisons don't see it.

## Closing

"The most common mistakes: marking reviewed without opening the result, and reviewing a partial. Remember: read the out-of-range values first. Mark reviewed tells the team the result is safe to release."
